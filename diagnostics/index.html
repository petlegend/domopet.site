Для ветеринарных специалистов

Экспресс-тесты Median Diagnostics

Направление, которым мы занимаемся кроме кормов. Экспресс-тесты позволяют получить результат прямо на приёме — не отправляя материал в лабораторию и не назначая владельцу повторный визит.

Это информация для специалистов. Тесты предназначены для ветеринарных врачей и клиник. Условия поставки, доступные позиции и документы обсуждаем индивидуально — напишите нам.

Производитель

Median Diagnostics

Корейская компания, которая разрабатывает и выпускает ветеринарные диагностические наборы с 1999 года. Производство находится в Чхунчхоне, Республика Корея.

Основная специализация — диагностика инфекционных болезней животных. Линейка включает экспресс-тесты (VDRG®), наборы ПЦР (VDx®) и ИФА (VDPro®).

Производство и документы

  • GMP для ветеринарных изделий для диагностики in vitro (2024)
  • GMP для изделий для диагностики in vitro (2021)
  • ISO 13485:2016 — система менеджмента качества (2020)
  • ISO 9001

По данным производителя. Копии документов предоставляем по запросу.

Тесты для кошек и собак

Что входит в линейку

Ниже — экспресс-тесты производителя для мелких домашних животных. Наличие конкретной позиции уточняйте у нас: ассортимент зависит от партии.

Набор Вид животного Что определяет
VDRG® CaFe Influenza Ag Кошки, собаки Антиген вируса гриппа
VDRG® CIV Ag Собаки Антиген вируса гриппа собак
VDRG® E.canis Ab Собаки Антитела к Ehrlichia canis
VDRG® Giardia Ag Кошки, собаки Антиген лямблий (Giardia)
VDRG® Leishmania Ab Собаки Антитела к Leishmania
VDRG® SFTSV Ag Кошки, собаки Антиген вируса SFTS

Результат экспресс-теста — основание для решения врача, а не диагноз сам по себе. Трактовать его и назначать лечение может только ветеринарный специалист.
